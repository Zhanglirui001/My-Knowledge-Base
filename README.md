# My-Knowledge-Base
一个基于本地文件夹 + Git 版本管理构建的多模态知识管理系统，原生支持 Markdown 文本（.md）、PDF 技术文献、可运行脚本代码（.sh/.py/.yaml）与 Draw.io 可视化架构图（.drawio）的无缝协同存储与版本追踪。

核心内容： 笔记不局限于纯文本，而是将核心编排脚本、系统架构图解与官方参考文献深度锚定在知识脉络中，实现“图文码”三位一体的立体化记录，杜绝理论与实战场景的脱节。

组织方式： 顶层采用 MOC（内容地图） 作为导航中枢，配合 卡片盒笔记法 进行原子化内容拆分。具体落地实行双轨制索引：

宏观分类：依托多层级文件夹进行粗粒度归档（如：/01-理论基础/、/02-工具实践/、/03-排障手册/、/04-架构图谱/）；

微观关联：借助 Markdown 文件的 YAML Frontmatter 标签系统（并为 PDF/绘图文件建立同级索引表）进行细粒度跨领域链接，让一篇 K8s 调度笔记能同时关联到对应的 deployment.yaml 代码文件和 network-policy.drawio 网络拓扑图。

通过“文件夹管宏观，标签管微观”的策略，确保每一份零散的报错日志、架构草稿或官方文档摘要，都能转化为可检索、可复用、可持续迭代的体系化知识资产。
