# 工作项目 MOC

## 用途

这里管理当前项目、项目复盘和项目中沉淀出的可复用知识。

## 当前项目

- 暂无。新项目建议放入 `10_Projects/项目名称/`。

## 项目笔记应该包含

- 背景与目标
- 关键决策
- 任务拆解
- 资料链接
- 风险和阻塞
- 复盘结论
- 可抽取为原子笔记的经验

## 项目结束后的处理

1. 项目资料归档到 `90_Archive/` 或保留在 `10_Projects/`。
2. 可复用经验提炼到 `40_Notes/`。
3. 重要结论挂回相关 MOC。
4. 输出物放入 `60_Outputs/`。
