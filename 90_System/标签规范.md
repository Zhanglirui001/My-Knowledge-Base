# 标签规范

标签用于横向连接，不用于替代文件夹。建议少而稳定，宁可先粗后细。

## 主题标签

表示内容属于什么领域。

```text
知识管理
AI
RAG
软件工程
产品设计
数据库
DevOps
系统设计
```

## 类型标签

表示内容是什么形态。

```text
概念
方法
案例
问题
经验
代码
论文
读书笔记
架构图
排障
```

## 状态标签

表示成熟度。

```text
inbox       临时记录，尚未处理
draft       初稿，有价值但还不稳定
evergreen   已沉淀，可长期复用
review      需要复查或更新
archived    已归档
```

## 用途标签

表示未来可能的使用方式。

```text
可写作
可复用
可项目化
待研究
待验证
```

## 使用规则

1. 每篇笔记至少包含一个主题标签和一个状态标签。
2. 不为一次性时间、地点、情绪创建标签。
3. 如果一个标签一个月只用一次，优先考虑合并。
4. 文件夹决定内容位置，标签决定内容关系。
