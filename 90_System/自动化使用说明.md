# 自动化使用说明

自动化入口是：

```powershell
python scripts/kb.py <command>
```

所有命令都只操作当前知识库目录。

## 创建原子笔记

```powershell
python scripts/kb.py new-note "RAG 中的知识切分策略" --tags "RAG,AI,方法" --moc "技术学习 MOC"
```

生成位置：

```text
40_Notes/YYYYMMDDHHmm-RAG 中的知识切分策略.md
```

## 创建 MOC

```powershell
python scripts/kb.py new-moc "RAG" --tags "RAG,AI"
```

生成位置：

```text
50_MOCs/RAG MOC.md
```

## 创建项目

```powershell
python scripts/kb.py new-project "本地知识库自动化"
```

生成位置：

```text
10_Projects/本地知识库自动化/README.md
```

## 分流 Inbox

先预览，不移动文件：

```powershell
python scripts/kb.py ingest-inbox
```

确认无误后执行：

```powershell
python scripts/kb.py ingest-inbox --apply
```

当前规则：

- `.pdf` -> `30_Resources/PDFs/`
- `.epub`、`.mobi` -> `30_Resources/Books/`
- `.drawio` -> `30_Resources/Drawio/`
- 常见代码和配置文件 -> `30_Resources/Code/`
- 常见图片 -> `_assets/`

执行后会生成：

```text
90_System/Inbox分流报告.md
```

对于被移动的资源，脚本会自动创建同名 Markdown 资料索引。

## 生成知识库体检报告

```powershell
python scripts/kb.py audit
```

生成位置：

```text
90_System/知识库体检报告.md
```

检查内容包括：

- 缺少 frontmatter 的 Markdown
- 缺少 tags 的 Markdown
- 缺少 status 的 Markdown
- 未挂 MOC 的原子笔记
- 孤立原子笔记
- 可能过大的原子笔记
- 高频标签统计

## 更新自动索引 MOC

```powershell
python scripts/kb.py update-index
```

生成位置：

```text
50_MOCs/自动索引 MOC.md
```

该文件会汇总 MOC、原子笔记、资料索引、项目和高频标签。建议把它当作自动生成文件阅读，不要手工维护列表内容。

## 推荐工作流

每周一次：

```powershell
python scripts/kb.py ingest-inbox
python scripts/kb.py ingest-inbox --apply
python scripts/kb.py audit
python scripts/kb.py update-index
```

如果你只想先看风险，执行第一条和第三条即可。
